WACV 2027 · Accepted 3D Visual Grounding

CC-3DVG: Prediction Consensus Reasoning for 3D Visual Grounding

A lightweight, plug-and-play consensus reasoning framework that improves the reliability of predictions produced by existing 3D visual grounding models. The project was developed end-to-end, from problem formulation and method design to implementation, experiments, analysis, and manuscript preparation.

Problem

Strong 3D grounding models can still produce unstable or competing predictions for the same language query. CC-3DVG studies how agreement among predictions can be used after generation to improve final localization.

Role

First-author project. Led problem formulation, method design, implementation, experimental evaluation, analysis, and paper writing.

Method

Post-generation consensus reasoning over candidate predictions with a lightweight design that can be attached to existing 3D visual grounding backbones.

Result

Improved ScanRefer Acc@0.50 by +1.49 percentage points while keeping the additional model overhead small.
